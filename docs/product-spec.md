# MVP Product Specification

## Product promise
Know what you promised. Know what's due.

## Target user
Small nonprofits and community organizations managing several awarded grants without dedicated grant-management software.

## Core workflow
Grant/Award → Obligations → Deadlines → Owners → Evidence → Status.

## V1 scope
- Awards
- Obligations
- Dashboard
- Ownership
- Evidence requirements
- Internal and funder deadlines
- Workflow status
- Local-first persistence
- Backup/export

## Explicitly out of scope for V1
AI extraction, grant discovery, grant writing, accounting integrations, CRM, cloud collaboration, email/SMS reminders, document storage, payment processing, and complex analytics.

## Acceptance criterion
A new user can create a grant, add obligations, assign owners, add deadlines and evidence requirements, see upcoming/overdue work, update status, export data, close the app, return, and still have their information.
